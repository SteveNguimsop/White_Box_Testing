# White Box Testing - Control Flow

## Project Description

This project implements a Python function called
Leap_Year(year) and demonstrates six testing
coverage techniques.

## Test Suites

1. Statement Coverage
2. Condition Coverage
3. Branch Coverage
4. Branch and Condition Coverage
5. Modified Condition/Decision Coverage (MC/DC)
6. Multiple Conditions Coverage (MCC)

## Running All Tests

python -m unittest discover -p "\*Tests.py" -v

## Testing Results

All 26 unit tests passed.

## Coverage Verification

The implementation changed throughout the project
to demonstrate different coverage requirements.

The Git history preserves the implementation and
test suite at each stage.

Python Coverage.py measures statement and branch
coverage. Condition coverage, MC/DC, and MCC
must also be justified using condition truth tables.
